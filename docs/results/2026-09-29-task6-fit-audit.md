- Rehashed the accepted bitstream and matched the receipt's SHA-256 exactly.
- Rehashed the three compiler sources listed in the postpass provenance; the current committed files match their recorded digests. At the initial audit, this corroborated only part of source identity. The committed Nix rebuild above subsequently closed the recipe gap.
- Read the native resource comparison, route receipt/log, postpass receipt, board receipt and accepted [board report](2026-09-29-compiler-full16-bram-board-acceptance.md).
- Built the committed Nix targets `task6-bram-postpass`, `task6-bram-image`, `task6-bram-synthesis`, `task6-bram-placement`, `task6-bram-route`, and `task6-bram-bitstream`. The rebuilt compiler control and two-ROM SV, normalized initialized SV, 89 image hashes, structural native netlist, sorted FASM features, frame file and decoded configuration all match their archived accepted counterparts. The rebuilt route reaches iteration 34 with zero overuse/architecture failures and reports 55.08 MHz on covered accelerator-clock paths at the unchanged 30 MHz constraint. The source closure deliberately excludes the physical-stage scripts from upstream derivations, so a route-script edit does not rerun synthesis.
- Built the committed `task6-bram-one-rom-comparison` target, which rebuilds the one-ROM ablation from the same compiler control and immutable model image, synthesizes it with the same native Yosys stages, and verifies every before/after cell count in the strategy table. Its source-normalized structural netlist hash `53d35315...36959` also matches the archived one-ROM netlist. This is a synthesis-only baseline, not a one-ROM fit or board claim.

## Task 6 decision

Task 6 is complete under the user-approved TinyStories-1M baseline and early-success stopping rule: the compiler-generated design fits, legally routes, and the archived configuration executed exact full-model autoregressive inference on the board. The [strategy comparison](../../resource_usage_reduction_strategies.org) and committed Nix reproduction command provide the survey, measured before/after result and usage recipe. Stop the strategy search; neither five additional strategies nor DDR3 inference is needed. The original v2 text's largest-Task-5-model baseline and 5–10-strategy minimum were explicitly revised by the user, not silently satisfied. NLnet acceptance of those deviations is not asserted. Task 4's interface/demo package and Task 5's scaling matrix remain separate work; full BRAM/DSP timing qualification is still not established.
