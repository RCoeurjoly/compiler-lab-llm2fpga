Pinned Yosys-Slang elaboration succeeds with zero frontend errors. The
subsequent generic `opt`/`memory` preparation is killed before emitting RTLIL

reachable in this clean path. This is a reproducible synthesis-memory frontier,

The next implementation step is to replace the monolithic preparation with
the repository's staged Yosys flow (bounded `begin:prepare`, memory mapping,
and per-stage receipts), preserving the checked-in BSCANE2 parameters and
static-image manifest at every boundary.

## Staged-flow evidence

That split has now been exercised. Clean elaboration emits
`/tmp/regen-clean/elab.il` (51 MiB, 2.35 GiB peak), and the pinned
`synth_xilinx -run begin:prepare` emits `/tmp/regen-clean/prepare.il` (56 MiB,
624 MiB peak). Both retain `JTAG_CHAIN=1` and `DISABLE_JTAG="FALSE"` on the
`csr.bscan` cell. A bounded arithmetic coarse pass (technology-map and
`alumacc`, deliberately omitting global `share` and `memory`) emits
`/tmp/regen-clean/coarse-raw.il` in 24 seconds at 748 MiB peak. The stock
coarse flow is confirmed to die in global SAT-based `share`; the standalone
`memory` pass also exceeds the interactive memory budget. The next blocker is
therefore staged BRAM legalization with the pinned Yosys architecture data,
not frontend elaboration or loss of the JTAG parameter.

## Memory-port diagnosis

The next bounded experiment separated `memory_collect` from mapping. Collection
itself succeeds in 3.7 seconds at 564 MiB peak and emits
`/tmp/regen-clean/collected.il`. Mapping then fails deterministically on
`core.token_weight_scale_q8_24_b3.mem` (32-bit × 16,384 words), which is marked
`ram_style=block`. Its collected `$mem_v2` cell has an asynchronous read
(`RD_CLK=1'x`, `RD_CLK_ENABLE=0`) and a synchronous write. The available
7-series BRAM mapping primitives require clocked read ports, so no valid BRAM
mapping exists for this generated memory. This is an actionable compiler-top
integration issue: the generated static model must introduce a registered
read boundary (or otherwise legalize asynchronous ROM/RAM accesses) before
BRAM mapping can succeed; changing the JTAG CSR or transport would not address
this failure.
